# DUKIN Cafe

Quy tắc cho các AI agent làm việc trong repo này.

## Agent skills

### Issue tracker

Issue được theo dõi trên GitHub Issues của repo (dùng CLI `gh`). Xem `docs/agents/issue-tracker.md`.

### Triage labels

Dùng năm nhãn triage mặc định, chuỗi nhãn trùng tên vai trò. Xem `docs/agents/triage-labels.md`.

### Domain docs

Bố cục đơn ngữ cảnh (single-context): một `CONTEXT.md` + `docs/adr/` ở gốc repo. Xem `docs/agents/domain.md`.
