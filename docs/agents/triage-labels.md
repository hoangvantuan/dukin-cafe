# Nhãn triage (Triage Labels)

Các skill nói bằng năm vai trò triage chuẩn. File này ánh xạ vai trò đó sang chuỗi nhãn thực tế dùng trong issue tracker của repo.

| Nhãn trong mattpocock/skills | Nhãn trong tracker của ta | Ý nghĩa                                    |
| ---------------------------- | -------------------------- | ------------------------------------------ |
| `needs-triage`               | `needs-triage`             | Người duy trì cần đánh giá issue này       |
| `needs-info`                 | `needs-info`               | Đang chờ người báo cáo bổ sung thông tin   |
| `ready-for-agent`            | `ready-for-agent`          | Đặc tả đầy đủ, sẵn sàng cho agent chạy AFK |
| `ready-for-human`            | `ready-for-human`          | Cần con người triển khai                   |
| `wontfix`                    | `wontfix`                  | Sẽ không được xử lý                        |

Khi skill nhắc tới một vai trò (ví dụ: "gán nhãn sẵn sàng AFK"), dùng chuỗi nhãn tương ứng trong bảng này.

Sửa cột bên phải để khớp bộ từ vựng bạn thực dụng.
